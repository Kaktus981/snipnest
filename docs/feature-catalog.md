# 文栈 SnipNest 功能候选库

本文件用于保留当前对话中已经讨论过的产品能力。后续用户要求添加功能时，先确认该需求是：

1. 启用本候选库中的已有功能；
2. 修改候选功能的设计；
3. 创建一个全新的功能。

未获得确认前，不将候选功能直接加入当前版本。

## 已选定并在 v0.1 实现

- 长文本自动保护与字段级历史，800ms 防抖、30秒检查点、最多5个版本。
- 草稿一键升级为永久片段。
- 根据字段标签、占位文字、名称和页面标题进行本地片段推荐。
- 网站逐个授权，支持撤销并显示保护状态。
- 临时草稿默认7天过期，可延长30天；永久片段不自动过期。
- 必要安全基础：敏感字段过滤、本地存储、JSON导出、全部数据清除。
- 任意非空短文本保护，默认从1字开始保存，并折叠展示1至9字短草稿。
- 意外清空保护：大段内容一次减少80%以上时保留删除前快照。
- 草稿按网站、日期或字段整理，并支持分组选择、批量延长和批量删除。
- 网站授权采用一次点击握手：权限确认后后台自动启用，并同步打开侧边栏。
- 侧边栏“当前页面”支持直接授权或停止保护网站，无需返回浏览器工具栏。
- 自动保存提供默认开启的用户开关；关闭后停止常规草稿与检查点写入，同时保留误删恢复保护。
- 隐私设置支持本地JSON导入，与现有草稿和片段按更新时间安全合并。

## 已讨论、尚未启用

- 同一片段的简短版、通用版、岗位版、英文版等多版本。
- 带变量、日期、下拉选择和占位符的动态模板。
- 求职、报名、售后等场景化“填写包”。
- 表单提交成功/失败感知和提交后的智能清理。
- 将旧网站草稿手动接力到新网站的跨站恢复流程。
- 历史版本差异对比和局部复制。
- 独立口令、Web Crypto 加密和自动锁定。
- 浏览器账号同步、端到端加密同步或自建同步。
- 云端 AI 或完全本地模型进行语义匹配。
- 复杂富文本框架、Shadow DOM 和跨域 iframe 适配。
- 团队共享、片段审批和组织模板。
- 完整表单档案和逐项填写进度。
- 提交记录、证据截图和可导出的办事档案。
- 常用片段使用统计、失效提醒和整理建议。
- Edge 商店发布材料、隐私政策和多语言界面。

## 明确不属于当前定位

- 密码、银行卡、验证码和证件信息保存。
- 抢购、预约、宏、自动点击、CAPTCHA 或整页无人值守填写。
- 默认读取所有网站、广告、遥测和出售用户数据。

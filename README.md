# 文栈 SnipNest

文栈是一款面向 Microsoft Edge 的本地长文本保险箱。它只在用户明确授权的网站工作，自动保护网页中的长文本，并允许将有价值的草稿升级为可跨网站复用的永久片段。

## 首版功能

- 按网站单独授权，不默认读取所有网页。
- 保护 `textarea`、普通长文本框和常见 `contenteditable`。
- 输入停顿约800毫秒后保存最新草稿，失焦或连续编辑30秒时建立历史版本。
- 默认从第1个非空字符开始保护，1至9字短草稿会折叠整理。
- 大段内容突然清空或减少80%以上时保留删除前快照，可一键恢复。
- 草稿可按网站、日期或字段分组，并支持批量延长和删除。
- 每个字段保留最近5个历史版本，临时草稿默认7天后删除。
- 草稿可延长30天或升级为永久片段。
- 根据字段标题、占位文字、字段名和页面标题在本地推荐片段。
- 排除密码、验证码、支付、证件和文件上传字段。
- 支持本地 JSON 导出和一键清除全部数据。

## 安装到 Edge

### 普通用户

1. 在 GitHub 的 Releases 页面下载最新 `SnipNest-*-edge.zip`。
2. 将 ZIP 完整解压到一个长期保留的文件夹。
3. 在 Edge 地址栏打开 `edge://extensions`。
4. 打开“开发人员模式”。
5. 点击“加载解压缩的扩展”，选择刚才解压的文件夹。
6. 将“文栈 SnipNest”固定到工具栏。
7. 打开普通 `http` 或 `https` 网页，点击扩展图标并选择“保护并打开文栈”。首次使用该网站时，在 Edge 权限框点击“允许”即可；侧边栏会同步打开并自动变为保护状态，不需要第二次点击。

### 开发者

1. 运行 `npm install`。
2. 运行 `npm run check`。
3. 在 Edge 的 `edge://extensions` 中加载项目生成的 `dist` 目录。

授权后请刷新已经打开的网页，或直接继续在当前网页输入。点击长文本字段时，右侧会出现“文”字入口。

## 开发命令

```bash
npm run dev
npm run test
npm run build
npm run check
```

`npm run build` 会生成图标、执行 TypeScript 类型检查并输出可加载的 `dist`。

## 手工验收

请使用项目根目录的 `启动测试网站.cmd` 启动完整本地测试站，并按照 [测试教程.md](测试教程.md) 验证短文本保护、误删恢复、草稿分组、批量操作、敏感字段过滤、片段推荐和权限撤销。

## 数据与隐私边界

- 正文存储在扩展自身的 IndexedDB 中，设置和授权状态存储在 `chrome.storage.local`。
- 当前版本没有账号、服务器、遥测、广告或网络请求。
- 本地存储不等于能够抵御本机恶意软件或已经取得系统权限的攻击者。
- 导出的 JSON 文件包含正文，请保存在可信位置；本地数据默认未加密，不能抵御已取得本机或 Edge 配置目录权限的恶意程序。

功能候选和后续确认规则见 [docs/feature-catalog.md](docs/feature-catalog.md)。当前扩展版本为 `v0.2.2`。

## 零基础全功能测试站

双击项目根目录的 `启动测试网站.cmd`，然后在 Edge 打开：

```text
http://127.0.0.1:4173/test-site/
```

测试站完全在本机运行，不会上传测试文字。第一次使用浏览器扩展时，请按照 [测试教程.md](测试教程.md) 从安装、授权开始逐步测试。
